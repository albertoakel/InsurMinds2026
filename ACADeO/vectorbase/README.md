# Vectorbase

Neste MVP, o diretório `vectorbase` é utilizado como área de persistência local.

O banco atualmente utilizado é:

`vectorbase/apolices.db`

Apesar do nome do diretório, o projeto **não utiliza um banco vetorial neste MVP**. O armazenamento é feito em SQLite. O diretório foi mantido separado para permitir uma futura evolução para recursos de busca semântica/RAG, se necessário.
